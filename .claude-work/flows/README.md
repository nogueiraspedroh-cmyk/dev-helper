# Flows — registro de execuções

Cada tarefa concluída pelo fluxo de `docs/PLANEJAMENTO.md` deixa aqui um registro
do que foi feito. Serve de histórico para entender decisões depois e alimenta o
fluxo de melhoria contínua dos agentes (`docs/MELHORIA-CONTINUA-AGENTES.md`).

## Convenção

- Um arquivo por tarefa: `AAAA-MM-DD-<slug-da-tarefa>.md`
  (ex.: `2026-06-23-ferramenta-json.md`).
- Conteúdo sugerido:
  - **Demanda** e critérios de aceite.
  - **Etapas** executadas e qual agente fez cada uma.
  - **Arquivos alterados/criados.**
  - **Iterações** (o que o code review apontou, o que voltou ao dev).
  - **Resultado** da validação (nginx local) e Definition of Done.
  - **Decisões/observações** que valham para tarefas futuras.
