Gerador de QR Code

Gere um QR Code a partir de qualquer texto ou URL — sem bibliotecas externas. Escolha o nível de correção de erro e baixe como PNG.

Nível de correção de erro

O que é um QR Code?

Um QR Code (Quick Response Code) é um código de barras bidimensional capaz de armazenar textos, URLs, dados de contato e muito mais. Ele é lido por câmeras de celular e leitores dedicados. A informação fica codificada nos quadradinhos (módulos) pretos e brancos; os três grandes quadrados nos cantos são os finder patterns, que ajudam o leitor a localizar e orientar o código.

Correção de erro

Todo QR Code inclui correção de erro Reed-Solomon: parte dos dados é redundante, então o código continua legível mesmo parcialmente danificado, sujo ou coberto. Há quatro níveis:

  • L — recupera ~7% dos dados. Gera o menor código.
  • M — ~15%. Bom equilíbrio (padrão).
  • Q — ~25%. Mais robusto.
  • H — ~30%. Máxima tolerância a danos; útil quando você vai colocar um logotipo sobre o código.

Quanto maior o nível de correção, mais dados de redundância — e, portanto, um código ligeiramente maior para a mesma informação.

Como este gerador funciona

O código é gerado inteiramente no seu navegador, com uma implementação própria do algoritmo de QR (codificação em modo byte com UTF-8, correção de erro Reed-Solomon, montagem dos padrões e escolha automática da melhor máscara). Não há bibliotecas externas nem CDN. A versão do QR (de 1 a 40) é escolhida automaticamente conforme o tamanho do conteúdo.

Perguntas frequentes (FAQ)

Qual o tamanho máximo de texto?

Depende do nível de correção. No nível L, um QR versão 40 comporta até cerca de 2.953 bytes (menos para acentos e emojis, que ocupam mais de um byte em UTF-8). Se o texto não couber, a ferramenta avisa e sugere encurtá-lo ou usar um nível de correção menor.

Consigo baixar o QR Code?

Sim. O botão "Baixar PNG" exporta a imagem gerada no <canvas> como um arquivo PNG, com margem clara (quiet zone) ao redor, essencial para a leitura.

Posso gerar um QR para conectar a uma rede Wi-Fi ou um contato?

Sim, indiretamente: basta colar o texto no formato que os leitores entendem — por exemplo, WIFI:T:WPA;S:NomeDaRede;P:senha;; para Wi-Fi. A ferramenta gera o QR de qualquer texto; o significado é interpretado pelo aplicativo que fizer a leitura.
