Formatador e Ajustador de XML

Cole seu XML abaixo para formatar, minificar ou verificar a sintaxe (well-formedness).

O que é XML e para que serve esta ferramenta?

XML (eXtensible Markup Language) é um formato de marcação usado para estruturar dados de forma hierárquica e legível — presente em arquivos de configuração, feeds (RSS/Atom), documentos Office, SOAP, sitemaps e integrações legadas entre sistemas. Diferente do JSON, o XML descreve estrutura por meio de tags e atributos, e permite conteúdo textual misturado com elementos.

Esta ferramenta processa o XML inteiramente no navegador, com um parser próprio (não usa o DOMParser do navegador), oferecendo três operações principais:

  • Formatar (pretty-print): adiciona indentação configurável (2 espaços, 4 espaços ou tab) e uma tag por linha, facilitando a leitura de um XML minificado ou gerado por sistema.
  • Minificar: remove espaços e quebras de linha desnecessários entre tags, reduzindo o tamanho do documento.
  • Verificar sintaxe (well-formedness): identifica tags não fechadas, atributos sem aspas, entidades inválidas e outros problemas estruturais, com uma mensagem de erro legível indicando a posição aproximada.

Elementos com conteúdo misto (texto e tags no mesmo elemento, como <p>Olá <b>mundo</b>!</p>) não são reindentados por dentro — adicionar quebras de linha nesse caso mudaria o texto original, então a ferramenta preserva esse trecho exatamente como está.

Perguntas frequentes (FAQ)

A ferramenta valida contra um XSD ou DTD?

Não. Esta ferramenta verifica apenas se o documento é bem formado (well-formed) — tags corretamente abertas/fechadas, atributos válidos, um único elemento raiz etc. Ela não valida a estrutura semântica contra um schema XSD ou DTD (isso exigiria carregar e interpretar um arquivo de schema separado, fora do escopo desta ferramenta).

A ferramenta expande entidades declaradas em DOCTYPE?

Não. Se o documento tiver uma declaração <!DOCTYPE ...> — inclusive com um subconjunto interno definindo entidades customizadas — ela é preservada como texto opaco entre a declaração XML e o elemento raiz, mas não é processada. Expandir entidades de DOCTYPE é uma superfície clássica de ataque (XXE) e foi deliberadamente deixado fora do escopo desta ferramenta.

Quais entidades são suportadas no texto?

As cinco entidades básicas do XML (&lt;, &gt;, &amp;, &quot;, &apos;) e entidades numéricas (&#65; ou &#x41;). Qualquer outra entidade nomeada (que dependeria de um DOCTYPE para ser resolvida) é reportada como erro.

O que significa um erro de "well-formedness"?

Indica que o texto não segue as regras estruturais do XML — por exemplo, uma tag de abertura sem a de fechamento correspondente, mais de um elemento raiz no documento, um atributo sem aspas, ou aspas de atributo não fechadas.
