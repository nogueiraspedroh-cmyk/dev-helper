Formatador e Verificador de JSON

Cole seu JSON abaixo para formatar, minificar ou verificar a sintaxe.

O que é JSON e para que serve esta ferramenta?

JSON (JavaScript Object Notation) é um formato leve de troca de dados, amplamente usado em APIs REST, arquivos de configuração e comunicação entre serviços. Sua sintaxe é legível por humanos e facilmente processada por máquinas — o que o tornou o padrão de fato para dados estruturados na web.

Esta ferramenta permite três operações principais diretamente no navegador:

  • Formatar (pretty-print): adiciona quebras de linha e indentação configurável (2 espaços, 4 espaços ou tab), tornando o JSON legível para depuração e revisão de código.
  • Minificar: remove espaços, quebras de linha e caracteres desnecessários, reduzindo o tamanho do payload antes de salvar ou transmitir.
  • Verificar sintaxe: identifica erros de formatação — chaves não fechadas, vírgulas extras, aspas faltando — e exibe a mensagem de erro do parser com a posição aproximada do problema.

Perguntas frequentes (FAQ)

Qual é a diferença entre formatar e minificar?

Formatar adiciona indentação e quebras de linha para facilitar a leitura humana. Minificar faz o oposto: gera uma string compacta, sem espaços extras, ideal para produção (menor tamanho de payload, menor consumo de banda).

O que significa um erro de sintaxe no JSON?

Um erro de sintaxe indica que o texto não segue as regras do formato JSON. Causas comuns: usar aspas simples em vez de duplas, incluir vírgula após o último item de um objeto ou array, deixar chaves/colchetes sem par, ou incluir comentários (JSON não aceita comentários, diferente do JavaScript).

Posso usar tab como indentação?

Sim. Selecione a opção Tab no seletor de indentação antes de clicar em Formatar. A escolha entre espaços e tab é uma preferência de equipe — o JSON resultante é igualmente válido em qualquer uma das opções.

A ferramenta suporta JSON muito grande?

Sim, dentro dos limites de memória do navegador. Para arquivos muito grandes (acima de alguns megabytes), o processamento pode ser mais lento. Nenhuma limitação artificial de tamanho é imposta pela ferramenta.
