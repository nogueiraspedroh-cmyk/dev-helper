Conversor YAML ↔ JSON

Converta YAML → JSON e JSON → YAML nos dois sentidos. O parser YAML é simplificado e escrito à mão (sem bibliotecas externas) — veja abaixo exatamente o que é suportado.

Direção

Sobre o parser YAML simplificado

YAML é um formato de serialização de dados muito usado em arquivos de configuração (Docker Compose, Kubernetes, CI/CD, etc.). O padrão completo é grande e cheio de recursos avançados. Para manter este site 100% estático e sem dependências, o parser aqui é uma implementação própria que cobre o subconjunto mais comum do YAML — o suficiente para a maioria dos arquivos de config do dia a dia.

O que é suportado

  • Mapas (chave: valor) e listas (- item).
  • Aninhamento por indentação usando espaços.
  • Escalares: string, número (inteiro e decimal), booleano (true/false) e null (null ou ~).
  • Aspas simples e duplas em valores e chaves, com escapes básicos nas aspas duplas (\n, \t, \", \\).
  • Comentários com # (inclusive no fim da linha).
  • Forma compacta - chave: valor para listas de objetos.
  • Coleções vazias [] e {}.

O que NÃO é suportado

  • Âncoras e aliases (&, *).
  • Tags (!!str, !!int, etc.).
  • Múltiplos documentos no mesmo arquivo (o separador --- é ignorado; use um documento por vez).
  • Blocos literais e dobrados (| e >).
  • Coleções inline não-vazias ([1, 2, 3] ou {a: 1}) — use a forma em bloco, indentada.
  • Tabs na indentação (o YAML padrão também não permite) — use espaços.

Se a entrada usar um recurso não suportado, a ferramenta exibe uma mensagem de erro legível em vez de produzir um resultado silenciosamente errado.

Perguntas frequentes (FAQ)

Por que não usar uma biblioteca YAML pronta?

O site é estático e sem etapa de build ou dependências externas (além do necessário para anúncios). Um parser próprio e enxuto mantém essa promessa e roda inteiramente no seu navegador.

Uma string que parece número é preservada?

Sim. Ao gerar YAML a partir de JSON, valores de texto que se pareceriam com números, booleanos ou null são automaticamente colocados entre aspas, para que a leitura de volta continue tratando-os como texto.

Recebi um erro de indentação. O que fazer?

Confira se você está usando espaços (não tabs) e se os níveis estão alinhados de forma consistente. A mensagem de erro indica a linha problemática.
