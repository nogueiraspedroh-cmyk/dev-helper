Gerador de Dados Fake / Mock JSON

Escolha a quantidade de registros e quais campos incluir, e gere um array JSON de objetos mock — ideal para popular protótipos, testes e demos.

até

Para que serve um gerador de dados mock?

Ao construir uma interface, um endpoint ou uma planilha de exemplo, muitas vezes você precisa de dados realistas mas fictícios para preencher listas, tabelas e cards. Digitar tudo à mão é lento; usar dados reais levanta questões de privacidade. Este gerador cria um array JSON com a quantidade de registros e os campos que você escolher — pronto para copiar no seu código, num arquivo de fixtures ou num mock de API.

Campos disponíveis

id (inteiro incremental começando em 1), uuid (identificador v4), nome (nome + sobrenome), email (derivado do nome, no domínio example.com), número inteiro dentro de uma faixa que você define, boolean, data (formato AAAA-MM-DD) e um texto curto no estilo lorem ipsum.

Perguntas frequentes (FAQ)

Os dados são reais?

Não. Nomes, e-mails e textos são combinados a partir de listas fixas e de números aleatórios, sem qualquer relação com pessoas reais. O domínio example.com é reservado para exemplos (RFC 2606) e não recebe e-mails.

Qual o limite de registros?

Até 1000 por geração, para manter a resposta instantânea e o JSON manejável.
