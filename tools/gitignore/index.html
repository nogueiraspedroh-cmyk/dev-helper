Selecione as linguagens, frameworks e ferramentas do seu projeto e monte um arquivo .gitignore combinando os blocos correspondentes. Copie ou baixe o resultado. Os padrões ficam embutidos na página — não há chamada a nenhuma API.

Linguagens, frameworks e ferramentas

Selecione ao menos uma opção acima para gerar o arquivo.

O que é um .gitignore?

O arquivo .gitignore diz ao Git quais arquivos e pastas não devem ser versionados: dependências instaladas (node_modules/, vendor/), artefatos de build (dist/, target/), arquivos de ambiente (.env), caches e metadados do sistema operacional ou do editor. Mantê-los fora do repositório reduz o tamanho, evita conflitos e previne o vazamento acidental de segredos.

Como funciona

Cada opção corresponde a um bloco de padrões testados para aquela tecnologia. Ao marcar várias, os blocos são concatenados na ordem, cada um com um comentário de cabeçalho (por exemplo # Node) para você saber de onde veio cada regra. Você pode copiar o conteúdo ou baixá-lo já com o nome .gitignore.

Conjunto disponível

A ferramenta cobre um conjunto prático: Node, Python, Java, Go, PHP, Ruby, Rust, .NET, os frameworks React e Angular, os editores VS Code e JetBrains, e os sistemas macOS, Windows e Linux. Os padrões são um ponto de partida sólido — ajuste conforme a necessidade do seu projeto.

Perguntas frequentes (FAQ)

Os padrões vêm da API do GitHub?

Não. Para manter o site sem backend, o dataset é estático e embutido no próprio JavaScript da página. Isso significa que funciona offline e sem depender de serviços externos, ao custo de não ser tão exaustivo quanto os templates oficiais.

Posso combinar várias tecnologias?

Sim — marque quantas quiser. Alguns padrões podem se repetir entre blocos (por exemplo node_modules/ em Node e React); isso é inofensivo para o Git.

Onde coloco o arquivo?

Na raiz do repositório. Regras em um .gitignore valem para a pasta onde ele está e suas subpastas. Arquivos já rastreados pelo Git precisam ser removidos do índice (git rm --cached) para o ignore passar a valer.
