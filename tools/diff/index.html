Diff de Texto

Compare dois textos e veja as diferenças destacadas — por linha ou por palavra, com adições e remoções coloridas. O cálculo usa o algoritmo LCS.

Granularidade

Para que serve um diff?

Um diff mostra o que mudou entre duas versões de um texto: quais linhas (ou palavras) foram adicionadas, quais foram removidas e quais permaneceram iguais. É a base de ferramentas de controle de versão como o Git e de revisões de código, mas também é útil para comparar contratos, textos, configurações e qualquer par de documentos parecidos.

Como a comparação funciona

A ferramenta usa o algoritmo da maior subsequência comum (LCS, do inglês Longest Common Subsequence). Ele encontra a maior sequência de trechos que aparecem na mesma ordem nos dois textos — esses trechos são os "iguais". Tudo que sobra do lado do Texto A é marcado como removido, e o que sobra do lado do Texto B é marcado como adicionado. Esse é o mesmo princípio matemático por trás dos diffs clássicos.

Por linha ou por palavra

  • Por linha — ideal para código e listas: cada linha é comparada como um todo, e as linhas alteradas aparecem uma removida (vermelha) seguida de uma adicionada (verde).
  • Por palavra — ideal para prosa: destaca dentro do parágrafo apenas as palavras que mudaram, mantendo o restante do texto como está.

Perguntas frequentes (FAQ)

Existe limite de tamanho?

O algoritmo LCS usa uma tabela proporcional ao produto dos tamanhos dos dois textos. Para não travar a aba, há um limite de segurança; se ele for atingido, a ferramenta avisa e sugere usar o modo por linha ou reduzir o conteúdo.

O resultado é seguro se eu colar código?

Sim. Todo o texto comparado é inserido no resultado como texto puro (via textContent), nunca como HTML — não há risco de que tags ou scripts colados sejam executados.

O diff mostra a menor mudança possível?

Sim. Por usar LCS, o número de adições e remoções é o mínimo necessário para transformar o Texto A no Texto B, na granularidade escolhida.
