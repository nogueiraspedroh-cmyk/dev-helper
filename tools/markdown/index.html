Editor / Preview de Markdown

Escreva Markdown e veja o resultado ao vivo. A renderização é feita de forma segura, construindo os elementos via DOM (sem innerHTML), então textos e links do seu conteúdo nunca viram HTML executável.

O que é Markdown?

Markdown é uma linguagem de marcação leve, criada para escrever texto formatado usando uma sintaxe simples de ler e escrever. É amplamente usada em READMEs, documentação, issues do GitHub, fóruns e anotações. Este editor converte o Markdown em HTML e mostra o resultado imediatamente ao lado.

Sintaxe suportada

  • Títulos — de # a ###### (h1 a h6).
  • Negrito — **texto**.
  • Itálico — *texto*.
  • Código inline — `código`.
  • Blocos de código — delimitados por três crases.
  • Listas — com -/* ou numeradas (1.).
  • Links — [texto](url).
  • Citações — linhas iniciadas por >.
  • Linha horizontal — ---.
  • Parágrafos — blocos de texto separados por linha em branco.

Segurança do preview

Como o preview é HTML renderizado de verdade, ele foi construído com atenção especial a XSS. Todo o conteúdo é montado com document.createElement e textContent — nunca innerHTML. A URL de cada link é validada: apenas http:, https:, mailto: e caminhos relativos são aceitos; esquemas como javascript: são recusados e o link vira texto simples.

Perguntas frequentes (FAQ)

Qual subconjunto de Markdown é suportado?

O descrito acima. Fora de escopo (por ora): tabelas, imagens, HTML embutido, listas aninhadas, listas de tarefas, notas de rodapé, ênfase com _/__ e realce de sintaxe nos blocos de código.
