Gerador de Meta Tags / Open Graph

Preencha os campos e gere o bloco de meta tags (Open Graph + Twitter Card + description) para colar no <head> do seu site. Veja também um preview do card de compartilhamento. É geração manual — a ferramenta não acessa nem faz scraping de URL nenhuma.

Preview do card

Para que servem as meta tags de compartilhamento?

Quando alguém compartilha um link no WhatsApp, LinkedIn, Facebook, X (Twitter) ou Slack, essas redes leem as meta tags Open Graph (og:*) e Twitter Card (twitter:*) do <head> da página para montar o cartão de pré-visualização: título, descrição, imagem e domínio. Sem elas, o link aparece "sem graça" ou com informações erradas.

Como usar

Preencha os campos, copie o bloco gerado e cole dentro do <head> de cada página (idealmente uma por página, com valores específicos). A og:image deve ser uma URL absoluta e, para o card grande, recomenda-se uma imagem em torno de 1200×630 px (proporção ~1.91:1).

Perguntas frequentes (FAQ)

A ferramenta busca os dados de uma URL automaticamente?

Não. Este site é 100% estático (sem backend), então não há como fazer fetch ou scraping de páginas externas. A geração é manual: você digita os valores e a ferramenta monta as tags e o preview.

O preview é exatamente igual ao de cada rede?

É uma aproximação. Cada rede tem seu layout, limites de caracteres e regras de cache próprias. Use o preview como referência e valide no depurador oficial de cada plataforma.
