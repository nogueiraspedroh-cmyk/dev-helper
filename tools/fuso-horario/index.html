Conversor de Fuso Horário

Escolha uma data e hora de referência e o fuso de origem; veja o horário equivalente em vários fusos ao redor do mundo. Usa a API nativa do navegador (Intl.DateTimeFormat), com horário de verão automático.

FusoData e hora localOffset

Como funciona

A ferramenta interpreta a data e a hora que você informou como o horário de parede no fuso de origem escolhido, converte esse momento para o instante universal (UTC) e então exibe o horário correspondente em cada fuso da lista. Tudo com a API Intl.DateTimeFormat nativa, sem bibliotecas externas.

Sobre os fusos (IANA) e horário de verão

Os fusos usam os identificadores IANA (como America/Sao_Paulo ou Asia/Tokyo). Esses identificadores carregam as regras históricas de cada região, incluindo horário de verão (DST). Por isso o offset exibido pode variar conforme a data escolhida — por exemplo, Nova York aparece como UTC-05:00 no inverno e UTC-04:00 no verão.

Perguntas frequentes (FAQ)

Posso adicionar outros fusos?

Sim. Use o seletor "Adicionar fuso à lista" para incluir mais fusos, e o botão "Remover" em cada linha para tirar os que não interessam.

Os horários levam em conta o horário de verão?

Sim. Como usamos os identificadores IANA e a API nativa do navegador, as transições de horário de verão são aplicadas automaticamente conforme a data de referência.
