Gerador de UUID

Gere identificadores únicos universais (UUID v4) usando a Web Crypto API — aleatórios e criptograficamente seguros.

Formatação

O que é um UUID?

Um UUID (Universally Unique Identifier), também chamado de GUID no mundo Microsoft, é um identificador de 128 bits projetado para ser único no espaço e no tempo sem precisar de uma autoridade central. É representado por 32 dígitos hexadecimais agrupados em cinco blocos separados por hífen, no formato 8-4-4-4-12 — por exemplo, 3f2504e0-4f89-41d3-9a0c-0305e82c3301.

UUIDs são muito usados como chaves primárias de banco de dados, identificadores de recursos em APIs, nomes de arquivos temporários e chaves de idempotência — situações em que gerar IDs únicos de forma distribuída (em vários servidores, sem coordenação) é essencial.

O que é o UUID v4?

A versão 4 é a mais comum: quase todos os seus bits são aleatórios. Esta ferramenta usa crypto.randomUUID() quando disponível — ou, como alternativa, crypto.getRandomValues() — ambos geradores criptograficamente seguros da Web Crypto API. Isso garante aleatoriedade de alta qualidade, sem a previsibilidade do Math.random().

Com 122 bits efetivamente aleatórios, a probabilidade de colisão (dois UUIDs iguais) é astronomicamente baixa — na prática, desprezível mesmo gerando bilhões de identificadores.

Opções desta ferramenta

  • Quantidade: gere de 1 até 100 UUIDs de uma só vez.
  • Com/sem hífens: alguns sistemas preferem o UUID "cru", sem os separadores.
  • Maiúsculas/minúsculas: o padrão é minúsculo, mas alguns ambientes (ex.: GUID no .NET) exibem em maiúsculas.
  • Copiar: copie um UUID individual ou todos de uma vez (um por linha).

Perguntas frequentes (FAQ)

Posso usar estes UUIDs em produção?

Sim. Eles são UUID v4 válidos, gerados por um gerador criptograficamente seguro. São adequados para chaves de banco, identificadores de API e afins.

Dois UUIDs podem sair iguais?

Em teoria sim, mas a probabilidade é tão baixa que é considerada desprezível na prática. Seriam necessários bilhões de UUIDs gerados para que a chance de colisão se tornasse minimamente relevante.

Qual a diferença entre UUID e GUID?

São essencialmente a mesma coisa. GUID (Globally Unique Identifier) é o nome usado pela Microsoft; UUID é o termo do padrão RFC. O formato de 128 bits é idêntico.
