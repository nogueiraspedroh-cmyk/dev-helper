Gerador de PIX Copia e Cola / QR Code

Gere o código PIX Copia e Cola (padrão BR Code / EMV) e o QR Code de um PIX estático — sem bibliotecas externas. O CRC16 é calculado localmente.

O que é o PIX Copia e Cola?

O PIX Copia e Cola é uma cadeia de texto no padrão BR Code, que segue a especificação EMV® QR Code do Banco Central. Ela contém, em campos numerados (ID + tamanho + valor), os dados necessários para um pagamento: a chave PIX do recebedor, o nome, a cidade, o valor (opcional) e um identificador da transação. O mesmo texto pode ser transformado em um QR Code para leitura pelo app do banco.

Como este gerador funciona

Tudo é montado no seu navegador. Os campos são organizados no formato EMV, o valor é formatado com duas casas decimais, o nome e a cidade são normalizados (maiúsculas, sem acento) e, no fim, é calculado o CRC16-CCITT (polinômio 0x1021, valor inicial 0xFFFF, sem reflexão) sobre todo o payload já com 6304 anexado. O QR reaproveita o mesmo motor de geração da ferramenta de QR Code do site (Reed-Solomon, sem CDN).

Perguntas frequentes (FAQ)

É um PIX estático ou dinâmico?

Estático: os dados ficam embutidos no próprio código. Não há URL para uma cobrança (payload dinâmico), nem geração de location — apenas os campos do recebedor.

Por que o nome e a cidade perdem os acentos?

O padrão BR Code recomenda caracteres simples nesses campos. Por isso o nome (máx. 25) e a cidade (máx. 15) são convertidos para maiúsculas sem acentuação, evitando problemas de leitura em alguns aplicativos.

O que é o campo txid?

É um identificador da transação (campo 62, subcampo 05). Quando você não informa nada, o padrão adotado é ***, aceito para PIX estático. Se preferir, use um identificador alfanumérico de até 25 caracteres.
