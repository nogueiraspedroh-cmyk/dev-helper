O que é contado

Caracteres com espaços é o total de todos os símbolos, incluindo espaços e quebras de linha — é o número que redes sociais e mecanismos de busca costumam limitar. Caracteres sem espaços ignora qualquer espaço em branco. Palavras são sequências separadas por espaço. Linhas conta as quebras de linha, e parágrafos conta blocos separados por uma linha em branco.

Limites comuns

A ferramenta mostra o quanto falta (ou o quanto excedeu) para três limites frequentes: 280 caracteres de um post no X (Twitter), ~160 de uma meta description e ~60 de uma title tag — os dois últimos importantes para o SEO, porque o Google trunca o que passa disso nos resultados.

Perguntas frequentes (FAQ)

Emojis contam como um caractere?

Sim. A contagem usa code points Unicode, então um emoji (mesmo os compostos por pares substitutos) conta como um único caractere, como a maioria das plataformas faz.

Os limites são exatos para cada plataforma?

São valores de referência amplamente usados. Cada plataforma pode ter regras próprias (por exemplo, contar links de forma diferente), então trate-os como um guia, não como uma garantia.
