O que é uma expressão regular?

Uma expressão regular (regex) é um padrão que descreve um conjunto de strings. É usada para buscar, validar e extrair texto: encontrar todos os e-mails de um documento, validar um formato de telefone, trocar partes de uma string, e muito mais. Esta ferramenta usa o motor de regex do próprio JavaScript (o mesmo do método String.prototype.match), então os resultados refletem o comportamento do seu navegador.

As flags

  • g (global) — encontra todas as ocorrências, não só a primeira.
  • i (ignore case) — ignora maiúsculas/minúsculas.
  • m (multiline) — faz ^ e $ casarem no início/fim de cada linha, não só do texto todo.
  • s (dotall) — faz o . casar também quebras de linha.

Grupos de captura

Parênteses em uma regex criam grupos de captura: além de casar, eles guardam a parte correspondente para você reutilizar. Por exemplo, (\d{4})-(\d{2}) captura o ano e o mês separadamente. Grupos nomeados ((?<ano>\d{4})) recebem um nome em vez de um número. Esta ferramenta lista cada grupo capturado por correspondência.

Perguntas frequentes (FAQ)

O que acontece se eu digitar uma regex inválida?

A ferramenta mostra uma mensagem de erro legível (a mesma do motor JavaScript) e não quebra — o destaque simplesmente não é aplicado até você corrigir o padrão.

Por que uma regex com a* e flag g não trava a página?

Padrões que podem casar uma string vazia (largura zero) poderiam gerar um laço infinito. A ferramenta avança a posição manualmente após cada match vazio, exatamente como se recomenda fazer ao iterar RegExp.exec.

O destaque é seguro contra código malicioso no texto?

Sim. O texto de teste nunca é inserido como HTML. Cada trecho (com ou sem match) é adicionado ao resultado como nó de texto ou dentro de um <mark> via textContent, o que elimina o risco de XSS.
