Conversor CSV ↔ JSON

Converta CSV → JSON e JSON → CSV nos dois sentidos. O parser trata aspas, escapes ("") e vírgulas/quebras de linha dentro de campos citados (RFC 4180 básico).

Direção

O que faz esta ferramenta?

CSV (Comma-Separated Values) e JSON (JavaScript Object Notation) são dois formatos onipresentes para trocar dados tabulares. Planilhas, exports de banco de dados e relatórios costumam sair em CSV; APIs e arquivos de configuração falam JSON. Esta ferramenta converte entre os dois nos dois sentidos, direto no navegador.

Como o CSV é interpretado

O parser segue o essencial da RFC 4180: campos podem ser envolvidos em aspas duplas, e dentro deles vírgulas, quebras de linha e aspas escapadas como "" são tratadas corretamente. Você pode escolher o delimitador (vírgula, ponto e vírgula ou tab) e indicar se a primeira linha é o cabeçalho. Com cabeçalho, o resultado é um array de objetos; sem cabeçalho, um array de arrays.

Como o JSON vira CSV

Para o caminho inverso, o JSON precisa ser um array: ou de objetos (as chaves viram as colunas do cabeçalho, unindo as chaves de todos os itens) ou de arrays (cada array vira uma linha). Valores com vírgula, aspas ou quebra de linha são automaticamente escapados com aspas duplas.

Perguntas frequentes (FAQ)

Os números do CSV viram números no JSON?

Não — os valores do CSV são mantidos como texto propositalmente, para garantir que a ida e volta (CSV → JSON → CSV) preserve exatamente o conteúdo, sem risco de perder zeros à esquerda (por exemplo, um CEP 01000) ou arredondar números grandes.

O que acontece com um CSV malformado?

Se houver, por exemplo, aspas que abrem mas nunca fecham, a ferramenta mostra uma mensagem de erro legível em vez de gerar um resultado incorreto ou travar a página.

Posso converter JSON com objetos de chaves diferentes?

Sim. Ao gerar o CSV, a ferramenta reúne a união de todas as chaves na ordem em que aparecem; itens que não têm determinada chave ficam com a célula vazia.
