Identador e Formatador de SQL

Cole sua query SQL abaixo para formatar com indentação, padronizar palavras-chave ou minificar.

O que é formatação de SQL e para que serve esta ferramenta?

SQL (Structured Query Language) é a linguagem padrão para consultar e manipular bancos de dados relacionais como PostgreSQL, MySQL, SQLite, SQL Server e Oracle. Queries SQL escritas de forma compacta — em uma única linha ou sem indentação consistente — são difíceis de ler, revisar e depurar, especialmente quando envolvem múltiplos JOINs, subconsultas ou cláusulas condicionais longas.

Esta ferramenta realiza uma formatação heurística da query SQL diretamente no navegador. As operações disponíveis são:

  • Formatar: coloca cada cláusula principal (SELECT, FROM, WHERE, JOIN, GROUP BY, ORDER BY etc.) em uma nova linha com indentação configurável; itens da lista do SELECT separados por vírgula são colocados em linhas próprias; palavras-chave são opcionalmente padronizadas em maiúsculas.
  • Minificar: colapsa a query em uma única linha com espaços normalizados — útil para reduzir o tamanho de queries embutidas em código ou logs.
  • Indentação configurável: escolha entre 2 espaços, 4 espaços ou tab para atender ao padrão da sua equipe.

A ferramenta é útil para desenvolvedores que precisam inspecionar queries geradas por ORMs, revisar SQL de migração ou documentar consultas complexas de forma legível.

Perguntas frequentes (FAQ)

A ferramenta suporta todos os dialetos SQL?

Esta é uma formatação heurística baseada em palavras-chave, não um parser SQL completo. Ela reconhece as cláusulas mais comuns (SELECT, FROM, WHERE, JOIN, GROUP BY, ORDER BY, HAVING, LIMIT, OFFSET, INSERT INTO, VALUES, UPDATE, SET, DELETE FROM, UNION e variantes de JOIN). Sintaxes específicas de dialeto muito incomuns ou extensões proprietárias podem não ser formatadas de forma ideal.

Strings e comentários são preservados?

A ferramenta faz um esforço razoável para não quebrar literais entre aspas simples (ex.: 'valor'). No entanto, como não é um parser completo, strings que contenham palavras-chave SQL (ex.: 'select from') ou comentários (-- comentário, /* bloco */) podem não ser 100% preservados em todos os casos. Para queries com strings ou comentários complexos, verifique sempre o resultado antes de usar.

A query formatada é executável sem modificações?

Em geral sim — a formatação não altera a semântica da query, apenas reorganiza espaços em branco e quebras de linha. Porém, por tratar-se de uma formatação heurística, é sempre recomendável testar a query formatada no seu banco de dados antes de usar em produção.

Qual a diferença entre formatar e minificar?

Formatar expande a query com indentação e quebras de linha para facilitar a leitura humana. Minificar faz o oposto: produz uma única linha com espaços normalizados, ideal para uso em código ou comparação de queries.

Posso usar tab como indentação?

Sim. Selecione a opção Tab no seletor de indentação antes de clicar em Formatar. A escolha entre espaços e tab é uma preferência de equipe ou convenção do projeto.
